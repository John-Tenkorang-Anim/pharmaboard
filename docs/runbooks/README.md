# Runbooks

Every production alert must link to a runbook containing impact, signals, safe diagnosis, mitigation, rollback, escalation, and post-incident checks.

Required before the notice pilot:

- outbox backlog;
- push provider degradation;
- SMS provider degradation and failover;
- database saturation;
- failed or partial deployment;
- suspected publisher compromise;
- incorrect notice publication and withdrawal;
- backup restore and regional outage.
